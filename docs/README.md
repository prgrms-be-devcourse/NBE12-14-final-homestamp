# homestamp 문서

세입자와 집주인이 집 상태·수리·퇴거 정산 기록을 함께 남기는 반응형 웹, homestamp(homestamp.cloud)의 기획·설계 문서예요. **여기가 원본**이고, 노션 등은 사본이에요. 이 폴더만 읽으면 무엇을, 왜 그렇게 만드는지 알 수 있게 썼어요.

## 읽는 순서

| 순서 | 문서 | 무엇을 |
|---|---|---|
| 1 | `rules/00-개요.md` | 문제, 사용자, 다른 점, MVP 범위(하는 것·안 하는 것) |
| 2 | `rules/01-이야기로-보는-흐름.md` | 서윤(세입자)·정호(집주인) 이야기로 보는 전체 흐름 |
| 3 | `rules/GLOSSARY.md` | 용어. 화면·코드·문서는 이 말을 써요 |
| 4 | `rules/03-상태와-규칙.md` | 상태, 규칙, 보이는 범위, 불변식. 06이 정한 것이 **어떻게 움직이는지** |
| 5 | `rules/02-사용자-시나리오.md` | 시나리오별 흐름 |
| 6 | `rules/08-화면-기본-틀.md` | 화면 틀과 버튼 문구 |
| 7 | `rules/06-요구사항-명세.md` | 요구사항, 수용 기준, API, 오류 코드, 설정값. **기준점** |
| 8 | `rules/05-ERD-초안.md` | 테이블과 불변식 대응 |
| 9 | `rules/04-인프라-아키텍처.md` | 인프라, 배포, 보안, CI/CD, 협업 규칙 |
| 10 | `rules/09-프로젝트-구조.md` | 패키지, 계층, 의존 방향, 이름 짓기 |

- `decisions.md`: 결정 기록(유일). **왜 그렇게 정했는지**는 여기서 찾아요.
- `runbooks/`: 운영 절차(유출 대응).
- `setup.md`: AI 하네스(Claude·Codex), IDE 코드 서식, 로컬 실행 처음 설정. 이 저장소에서 작업하기 전에 한 번 따라 해요.
- `failure-memory.md`: AI가 반복한 실수 기록. AI가 작업 전에 읽고, 기록은 사람이 승인한 것만 더해요.
- 그림은 문서 안의 Mermaid 코드예요. GitHub에서 바로 그려져요.

## 문서끼리 다르면

**기준점은 `06-요구사항-명세.md`예요.** 06이 무엇을 만들고 어떤 결과여야 하는지(기능, 수용 기준, API, 오류 코드, 설정값)를 정하고, 다른 문서는 06에 맞춰요. 06 기능 표의 "규칙" 칸이 03의 어느 절인지 가리키니, 06을 먼저 보고 그 칸을 따라 03을 읽어요. 06에 없는 자세한 움직임(전이 순서, 한도 같은 것)은 아래 주제별 문서가 채워요.

주제마다 자세한 내용이 있는 문서는 이래요.

| 주제 | 기준 |
|---|---|
| 기능, 수용 기준, API, 오류 코드, 설정값 | `06-요구사항-명세.md` (기준점) |
| 상태, 규칙, 보이는 범위, 불변식 | `03-상태와-규칙.md` |
| 용어 | `GLOSSARY.md` |
| 테이블, 칸, 제약 | `05-ERD-초안.md` |
| 화면 틀, 버튼 문구 | `08-화면-기본-틀.md` |
| 컨벤션(브랜치·커밋·PR) | 루트 `AGENTS.md` |

서로 다르면 `06-요구사항-명세.md` → `03-상태와-규칙.md` → `GLOSSARY.md` → `05-ERD-초안.md` → `08-화면-기본-틀.md` 순서로 앞의 것이 맞아요. 단, `decisions.md` "늘 지키는 원칙"·03 5장 불변식·03 권한 표와 06이 다르면 어느 쪽도 자동으로 이기지 않고 `/decide`로 정한 뒤 고쳐요. 다른 곳을 발견하면 앞 문서에 맞춰 고치는 PR을 올려 주세요.

## 바꾸는 법

1. 규칙이 바뀌면 영향받는 문서를 모두 고쳐요(명세 → 상태와 규칙 → ERD → 화면 → 시나리오·이야기).
2. `decisions.md` 표 맨 아래에 한 줄(날짜, 결정, 이유) 더해요. `/decide 결정 / 이유`로 하면 돼요.
3. 둘을 **한 PR**로 `dev`에 올려요. 브랜치는 `docs/common/…`, PR 제목은 `docs: …`(팀 규칙은 루트 `AGENTS.md`).

넣지 않는 것: 기록 수정·삭제 기능, 판정·법적 판단 문구, 주민등록번호 처리, 외부 CDN·외부 OCR, 비밀값 커밋(`decisions.md` 원칙).
