# 결정 기록

> 정한 것이 바뀌거나 새로 정해질 때 한 줄씩 더하는 **유일한 결정 기록**이에요. 지금 기준의 내용은 `rules/` 문서에 있고, 여기에는 "언제, 무엇을, 왜"만 남겨요.
> 더하는 법: `/decide 결정 / 이유`(하네스 `decide` 스킬)로 **표 맨 아래**에 한 줄. 위가 오래된 것, 아래가 최신이에요. 바뀐 결정은 지우지 않고 새 줄에 `(YYYY-MM-DD 결정을 바꿈)`을 붙여요. 규칙 문서를 고쳤으면 같은 PR에 넣어요.

## 늘 지키는 원칙

1. 덧붙이기만 한다. 기록 수정·삭제 API 없음. 바로잡기는 고친 내용(새 기록). 예외: 개인정보가 찍힌 사진 파일만.
2. 사실은 혼자 남길 수 있고, 합의는 혼자 만들 수 없다.
3. 판정하지 않는다. 책임·과실·금액을 서버가 정하지 않고, 법적 판단 문구를 쓰지 않는다(법이 요구하는 고지 문장은 예외).
4. 기다림에는 끝이 있다. 48시간 뒤 다시 알리고, 24시간 더 지나면 "확인 없음". 혼자 진행은 정해진 요청(하자·종료·점검·정산 끝내기·거주 종료)만, 합의는 혼자 만들 수 없다.
5. 시각은 서버 시각만.
6. 관리 단위는 호실.
7. 개인정보는 기기에서 가리고 필요한 만큼만. 주민등록번호를 받지 않고, 외부 CDN·외부 OCR·외부 분석 도구를 쓰지 않는다.
8. 개인정보 보호 장치가 실패하면 막히는 쪽으로.
9. 비밀값과 액세스 키는 저장소·이미지·Terraform 파일에 두지 않는다. 앱은 EC2 역할 + Parameter Store, CI는 OIDC.
